NOWENZA PROFORMA PWA

GitHub Pages'e yuklenecek dosyalar:
- index.html
- style.css
- script.js
- manifest.json
- sw.js
- logo.png
- icon-180.png
- icon-192.png
- icon-512.png

GitHub Pages ayari:
Settings > Pages > Deploy from a branch > main > / (root)

iPhone:
1. GitHub Pages adresini Safari'de ac.
2. Paylas > Ana Ekrana Ekle.
3. Varsa "Web Uygulamasi Olarak Ac" secenegini ac.
4. Ekle.

Not: PWA kurulumu HTTPS uzerinden calisir. GitHub Pages HTTPS saglar.
